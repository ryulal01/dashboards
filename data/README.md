# Data

`listings.csv` — 80 синтетических объявлений: категория, регион, цена, дата публикации и статус.

`listing_daily_stats.csv` — дневные агрегаты просмотров, контактов и откликов за май 2025 года для каждого объявления.

Данные искусственные, сгенерированы для портфолио. Они не являются реальными данными Avito и не описывают фактическую аудиторию или бизнес-показатели компании.

Загрузка: см. `sql/00_load_csv_example.sql`.

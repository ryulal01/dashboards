# Метрики и методология

Все данные в репозитории синтетические и созданы для демонстрации аналитического процесса. Они не являются данными Avito.

| Метрика | Определение | SQL-расчёт |
|---|---|---|
| Просмотры (Views) | Сумма просмотров за выбранный период | `SUM(views)` |
| Контакты (Contacts) | Сумма переходов к контактам продавца | `SUM(contacts)` |
| Отклики (Responses) | Количество условных откликов | `SUM(responses)` |
| Конверсия в контакт | Доля просмотров, завершившихся контактом | `100 * SUM(contacts) / SUM(views)` |
| Доля откликов от контактов | Доля контактов, завершившихся откликом | `100 * SUM(responses) / SUM(contacts)` |
| Активные объявления с событиями | Число уникальных объявлений с активностью | `COUNT(DISTINCT listing_id)` |

## Ограничения

- События агрегированы на уровне объявления и дня.
- Контактная конверсия рассчитывается как отношение сумм, а не как среднее конверсий отдельных объявлений.
- В наборе нет персональных данных.
- Примеры запросов используют фиксированный период 1–31 мая 2025 года; при переносе в Redash можно добавить параметры периода.
